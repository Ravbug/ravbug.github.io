Command Description
/setcommand -t [trigger] -r [output] [other optional flags]

setimage -t [trigger] -url [image URL] [other optional flags]		 Specify trigger test and text to respond with. Use a valid regex for the trigger.
Flags
-r: Textual response to the command.
-url: Embed an image with the command.
-tr: Alternative to -t for advanced users. Specify an exact JS regex string and it will not be post-processed. If -t and -tr are present, the bot will execute the command if either succeed.
-inv: Invert the result of the trigger. If the trigger passes, this will make it false, and vice-versa.
-del: delete the trigger message
-tag: tag the user who triggered the command
-bc #channel1 #channel2 ...: prevent the command from running in the included list channels (can supply more than 2).
-ac #channel1 #channel2 ...: the command only runs in the included list channels (can supply more than 2). Ignores -bc. 
/edit [int] [new flags]
 Edit a command's data. Speficy the new flags to update, like you do for setcommand 
/delete [int]
 Delete the command with an ID. This is not undoable. 
/wipe
 Delete ALL commands. This is not undoable. 
/list
 List the commands for this server. 
/help
 Display this list of commands 
/about
 Get a link to this webpage 
/announce [#channel] [message]
 Posts a message in a channel. The bot must have write access to the destination channel.
